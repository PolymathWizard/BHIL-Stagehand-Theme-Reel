## Variant 1 · Technical authority

When an AI agent is asked to make a page "feel like an 80s broadcast" or "open like a title sequence," it usually improvises. Sometimes that improvisation is charming. Sometimes it is a copy of something a studio owns, flickering in a way that should never reach a screen.

So we wrote the rules down. The Stagehand Theme Codex is a set of motion themes for agents that build pages, reels and decks. Each theme is a costume layer with paste-ready tokens, a map of where its motion goes on a page, and a one-line Boardroom translation for when the audience is a leadership team rather than a fan community.

Three ideas hold it together. Evoke the genre, never the property. One theme, three volumes. And canon is the only source: every page, token file and the reel itself are generated, and the build fails if anything drifts.

The public edition is open now, with a self-contained reel that shows every theme running at all three volumes.

## Variant 2 · Inquiry-driving

What should an AI do when your brief says "make it cinematic"?

We think it should ask what the story is before it decides what it looks like. Then it should pick from a vetted set of looks that borrow a genre's grammar without borrowing anyone's property. Then it should turn the volume down for the boardroom. And then a second agent, one that never saw the designer's reasoning, should check the result.

That is how the Stagehand Theme Codex works, and the public edition is now on GitHub with the agent team, the prompts and a reel you can open in any browser.

If your team uses agents for creative work and you are wrestling with taste, safety or brand drift, I would like to hear how you are handling it.
